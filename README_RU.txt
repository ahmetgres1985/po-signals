PO SIGNAL PRO — версия 0.2 (промежуточный исходный проект)

Что добавлено в версии 0.2:
- Режим «все OTC-пары → показывать только сильные сигналы».
- Стартовый список из 10 пар для дальнейшего сканирования.
- Запрос системного разрешения Android на захват экрана через MediaProjection.
- Честное отображение этапа разработки: приложение не имитирует найденные сигналы.

Что пока НЕ реализовано:
- Фактический захват и обработка кадров экрана.
- Распознавание графика, свечей, Moving Average и RSI.
- Автоматическое переключение пар в Pocket Option.
- Расчёт достоверных сигналов CALL/PUT.
- Плавающее окно и уведомления о сигналах.

Следующий этап:
1. Реализовать MediaProjection foreground service для получения кадров.
2. Добавить распознавание графика и проверку качества изображения.
3. После проверки распознавания реализовать управляемое переключение пар с явным разрешением пользователя.
4. Проверять сигналы на демо-данных и только затем на демосчёте.

Сборка:
- Откройте папку проекта в Android Studio.
- Дождитесь синхронизации Gradle и установки Android SDK 35.
- Build > Build Bundle(s) / APK(s) > Build APK(s).

Важно: это промежуточная версия исходного проекта, не готовый торговый робот и не готовый APK. Сигналы не генерируются; не используйте для реальных сделок.
